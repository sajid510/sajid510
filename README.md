## Featured Project

### [Ultron UV](https://github.com/supersonic654e-byte/Ultron-UV-) — Autonomous Disinfection Robot

Research prototype of an autonomous hospital disinfection robot, built by Team Supersonic UAP. Maps and navigates indoor spaces using LiDAR and Kinect RGB-D on a Jetson Nano with an Arduino Mega motor layer, running ROS2, SLAM Toolbox and Nav2, with remote monitoring over Zenoh and Tailscale.

**Featured at the BEAR Innovation Expo 2026 in Dhaka.**
